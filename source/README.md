# Patissière — Сайт кондитерской

## Что это

Рабочий прототип сайта-витрины кондитерской в Порту (Португалия).
Клиенты могут выбирать вкусы, собирать заказ и оформлять его с указанием даты и способа получения.

---

## Файлы проекта

```
сайт финал/
├── sweet-thing-v2.html   ← ОСНОВНОЙ ФАЙЛ (весь сайт)
└── фото/                 ← папка с фотографиями изделий
    ├── IMG_0284.JPG
    ├── IMG_0787.JPG
    ├── ... (18 фото)
```

> Для запуска достаточно открыть `sweet-thing-v2.html` в браузере.
> Папка `фото/` должна лежать **рядом** с html-файлом.

---

## Технический стек прототипа

- **React 18** (через CDN, без сборки)
- **Babel Standalone** — JSX прямо в браузере
- **Чистый CSS** с переменными (`:root`), без фреймворков
- **Шрифты**: Italiana, Work Sans, Quicksand (Google Fonts)
- Никаких зависимостей, никаких `node_modules` — один HTML-файл

---

## Функциональность (уже реализована)

- [x] Двуязычный интерфейс: **RU / PT** (переключатель в шапке)
- [x] Секция **Тарталетки**: карусель вкусов, выбор 1 или 2 вкусов, счётчик
- [x] Секция **Эклеры**: выбор размера (2/3/4 шт), вкусов, счётчик
- [x] **Корзина** (drawer): группировка по типу, изменение кол-ва, удаление
- [x] **Оформление заказа**: имя, контакт (WhatsApp/Telegram/Телефон/Email), дата + календарь, слот времени, самовывоз / доставка
- [x] **Плавающая кнопка корзины** (FAB) — всегда видна при скролле
- [x] **Toast-уведомления** при ошибке выбора вкуса
- [x] **Галерея изделий** — две строки с автопрокруткой в разные стороны
- [x] **Адаптив**: desktop / tablet / mobile
- [x] Реальные фотографии изделий во всех блоках

## Важные заметки

1. **Нет бэкенда** — заказы никуда не отправляются, кнопка "Отправить заказ" только показывает экран подтверждения
2. **Цены** захардкожены в JS: тарталетки — €14, эклеры — €8/€11/€14
3. **Фото** — все портретные (телефонные), в карточках вкусов используется `object-fit: cover`
4. Все стили — **только классы**, никаких inline-стилей (кроме CSS-переменных и динамических трансформов карусели)
5. Компонент `useBreakpoint()` — используется только для числа элементов в карусели и условного рендера; весь адаптив — через CSS `@media`
